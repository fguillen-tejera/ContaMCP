Soporte

ContaMCP es un proyecto independiente de código abierto operado por Fernando Guillen. Ofrece herramientas de registro financiero para asistentes MCP compatibles con OAuth.

Conecta tu asistente

Utiliza esta dirección en un cliente MCP compatible con OAuth y continúa con Google o una cuenta de correo y contraseña creada por el operador:

https://contamcp.devbyfer.com/mcp

Tu identidad verificada selecciona tu registro privado. Si ya usas Google, sigue eligiendo Google; las cuentas de correo tienen un registro separado, incluso con el mismo correo. El asistente solo puede usar las herramientas y permisos que autorizas. La disponibilidad de conexiones MCP depende de tu asistente y de tu cuenta.

Guía de conexión · Código e instalación propia

Recibe ayuda

Para problemas de conexión o preguntas sobre privacidad, escribe a fernandoguillen.apps@gmail.com. Comparte la hora aproximada, el nombre del cliente y un ID de solicitud si lo tienes. No envíes tokens, contraseñas, registros financieros ni direcciones de retorno de OAuth.

Usa GitHub Issues para reportes públicos y propuestas con ejemplos ficticios. Para reportes de seguridad, sigue la política de seguridad del repositorio.

Servicio y datos

El servicio alojado está en una etapa inicial, usa infraestructura gratuita y puede alcanzar sus límites de recursos. Conserva tus propios respaldos con las herramientas de exportación. Los movimientos recurrentes son registros contables: no pagan facturas ni cancelan suscripciones.
