Support

ContaMCP is an independent open-source project operated by Fernando Guillen. It provides financial bookkeeping tools for OAuth-capable MCP assistants.

Connect your assistant

Use the following server URL in an MCP client that supports OAuth, then sign in with Google:

https://contamcp.devbyfer.com/mcp

Your Google identity selects your private ledger. The assistant can access only the tools and permissions you authorize. Availability of MCP connections depends on your assistant and account.

Connection documentation · Source code and self-hosting

Get help

For connection issues or privacy questions, email fernandoguillen.apps@gmail.com. Share the approximate time, client name and a request ID if available. Do not send access tokens, passwords, financial records or OAuth callback URLs.

Use GitHub issues for public bug reports and feature requests with synthetic examples only. For security reports, follow the repository's security policy.

Service and data

The hosted service is an early, best-effort service on free infrastructure and can encounter resource limits. Keep your own backups using the export tools. Recurring entries are bookkeeping records; they do not pay bills or cancel subscriptions.
